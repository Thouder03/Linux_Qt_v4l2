### 运行平台
任意Linux系统
### 功能
1.实时显示device0摄像头图像。

2.可以录制并用自定义的格式存储视频。

3.可以选择录制的视频并回放。

4.有视频进度条并可随意拖动。

### 参数
1.视频分辨率为320*240。

2.窗口大小为480*272。
### 部署
需要先在QT编译后放到对应的设备运行。
